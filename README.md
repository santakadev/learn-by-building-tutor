# learn-by-building-tutor

A Claude Code setup that turns Claude into a tutor for software engineers. You learn a topic by building a sequence of projects. The tutor plans the study, sizes each project to your current level, and guides you with questions. It never writes the code for you.

## Getting started

1. Clone this repository. It becomes your learning home.
2. Open Claude Code at its root.
3. Start a study with `/learn` followed by what you want to learn:

```
/learn build REST APIs with FastAPI
```

The tutor will ask about your motivation, assess your current level, and propose a learning plan. Once you approve it, it defines your first project and you start building.

Each study gets its own folder with its plan, progress log, and projects. You can start as many studies as you want.
